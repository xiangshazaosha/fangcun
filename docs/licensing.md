# 两项目统一许可：使用、改编与商业授权

## 定位与设计

方寸 FANGCUN 和点将台均采用根目录 [LICENSE](../LICENSE)：**笑爷非商业同许可源码公开许可 2.0**（`LicenseRef-Xiaoye-NC-Reciprocal-2.0`）。这是自定义 Source-available 许可，**不是 OSI 标准开源**。中文为解释正文，附完整英文译文。本说明不扩大正文授权。

设计是“非商业共享 + 对外提供时同许可公开源码 + 商业用途须另获书面授权”，不是“你拥有所有二创作品”。作者保留自己的权利。许可不能把一般思路、独立实现或第三方代码变成维护者的独占资产，也不保证全部 AI 产物享有著作权。

## 场景判定

| 场景 | 本许可的处理 |
|---|---|
| 个人学习、私下非商业运行/修改 | 允许，无须公开私下改版 |
| 单纯为实验支付模型/API/云服务费用 | 不因此自动成为商业用途；目的仍须非商业 |
| 非商业分享原版、改版、移植版或包含模板的演示 | 保留许可/署名，公开涵盖部分的完整对应源码 |
| 免费在线供人操作受限演示/工具或其改版 | 即使不收费、未修改，也须提供匹配版本的源码入口 |
| 改名、增加功能后卖产品、插件、课程或 Skill | 本许可不授权；须另获书面商业授权 |
| 给客户收费制稿、开发、培训、咨询、部署或维护 | 本许可不授权；“只收费服务”不能规避 |
| 企业内部业务、销售/营销、生产系统 | 不因不对外销售而免于商业授权要求 |
| 免费给用户，但靠广告/订阅/有对价赞助获益 | 仍可能属于商业用途，不因免费自动获授权 |
| 员工下班后的个人非商业学习 | 不因其就业身份自动禁止；不能借此服务雇主业务 |
| 学校/公益机构 | 按具体用途判断，身份不自动豁免商业行为 |
| 点将台调度工具生成的独立客户代码 | 不自动归维护者，也不自动要求公开；商业使用调度工具仍须授权 |
| 方寸导出的 HTML 包含原有受保护代码/模板 | 涵盖部分继续受约束，生成或打包不解除许可 |
| 不复制/改编受保护表达，仅独立实现相似思路 | 不自动纳入许可；需结合实际证据判断 |
| 独立使用 MIT/OFL 第三方组件或适用旧版授权 | 按各自有效许可，不被本许可追溯取消 |

## 怎么提供源码，不泄露客户资料

1. 在发行说明、下载页面、界面或同等显著位置放置匹配版本的源码链接。
2. 提供覆盖部分的首选修改形式：源码、自己的受限改动、模板、构建脚本、必要非敏感配置及依赖/版本说明；不要只发压缩产物、截图或一个不对应版本的首页。
3. 客户文稿、密钥、个人数据、业务数据、日志、会话和独立私有代码不要求公开。提供脱敏示例/配置占位符，使对应受限代码仍可修改和构建；不可用虚构私有依赖架空义务。
4. 分发包中保留 `LICENSE`、`NOTICE` 和适用第三方许可证，标注原项目、自己做了哪些修改。
5. 对外提供期间，以及最后一次提供后三年，源码入口持续可无偿获取，不加购买、保密协议或限制性新授权门槛。
6. 独立数据与代码无法安全分离时，先申请合适授权，不要求也不允许为合规而泄密。

原版源码链接可以对应到公开仓库的准确 commit/tag；修改版须提供实际改动后的源码，不能只链接原项目来代替。源码义务只覆盖真正受许可约束的内容，不是强迫公开整套客户仓库或任意独立相邻程序。

## 商业授权流程（不是现成授权）

通过 [维护者公开联系入口](https://github.com/xiangshazaosha)申请。请只在公开 issue 中放非敏感概要，不上传客户项目、密码、账户信息或商业秘密。

需要另行书面确定：双方主体、项目与版本、授权的实际用途、人数/部署/地域/期限、再分发或 SaaS 权利、源码公开义务是否豁免、费用/支付、归属与商标、其他权利人授权、责任和争议解决。示例清单本身不授予任何商用权。

维护者只能授权自己有权许可的部分。如果包含外部贡献、独立第三方或客户内容，须审查其他授权，必要时分别取得权利人同意；赞助、买模型额度、发 issue、无人回复或贡献代码，都不自动换取商业许可。

## 贡献与后续维护

贡献者保留自己的版权。提交合并前明确同意新增内容按本许可提供，说明来源与第三方许可；未确认可许可权利的内容不要合并。维护者接收 PR 不等于获得商业再许可权，更不等于受让版权。商业双许可若需要使用他人的贡献，应另取明确授权。

更新许可时，保存旧版，更新 README/包元数据/Skill 发行副本/导出器，并测试包中是否真的包含法律文件；不要只改首页一句话。无需把贡献者或用户的身份证、邮箱及敏感资料写进公共仓库。

## 违规、补救与维权

故意、重复或未经授权的商业使用不能靠“第一次被发现后改回来”自动恢复许可。首次非故意、非商业的可补救署名/源码遗漏有三十日补救路径；恢复不自动免除既往依法应承担的责任。

本许可不设自动罚款、固定违约金、授权费或赔偿；不保证胜诉。不以项目名称控制他人的独立作品，不以仓库提交时间代替权属证明。维权须评估可保护的具体表达、作者/雇佣/委托/贡献权属、许可适用、对方实际复制/改编与商业用途以及损失/获利证据。

正式商业合同及重大维权应由相应司法辖区的律师审阅。此自定义许可未经律师审定，以上是一般信息；适用国家/地区不同，效力及救济可能不同。
