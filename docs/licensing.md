| 场景 | 是否获本许可授权 |
|---|---|
| 个人非商业学习、实验，运行 Skill 和示例 | 是，遵守许可和第三方声明 |
| 非商业修改、分享本项目或衍生版本 | 是，保留许可、权利声明，标注修改 |
| 改名或改 UI 后作为付费产品出售 | 否，先取得单独书面授权 |
| 利用 Skill 或其模板给客户收费制稿 | 否，先取得单独书面授权 |
| 商业培训、咨询、SaaS、企业内部经营用途 | 否，先取得单独书面授权 |
| 单独使用第三方 Three.js、字体、MIT 原始部分 | 按该第三方许可证判断，不由本许可禁止 |
| 不复制受保护表达，独立实现相似的一般思路 | 不自动受本许可约束；思想、方法不是本项目独占资产 |

## 范围

- 许可只涉及权利人依法享有或有权许可的内容，不证明整个仓库或 AI 生成图片具有独占著作权。
- 用户自己的文稿、资料、商标及独立作品仍归对应权利人。本项目不因此取得客户作品的所有权。
- 导出的演示或背景若包含受限代码、模板或素材，应保留本许可及第三方许可；不要只复制 HTML 后丢掉法律文件。
- 商业用途包括间接商业利益，不仅仅是“出售代码”。仅更名或仅以服务名义收费不解除限制。
- 如需商业授权，通过仓库维护者联系入口申请；双方另行明确主体、范围、期限、费用及责任。不要在公开 issue 中提交个人敏感信息。

## 关于起诉与赔偿

禁止商业使用是授权边界，不是自动赔偿承诺。能否维权以及金额取决于权利归属、作品的可保护性、适用法律、是否确实复制/改编受保护表达、许可效力及损失/获利等证据。不能仅凭“我先传了 GitHub”就主张所有相似项目侵权。

若适用中国大陆法律，《著作权法》第五十四条规定赔偿可以按实际损失、违法所得或参照权利使用费确定；难以计算时的法定赔偿范围为 500 元至 500 万元，故意且情节严重才可能适用一至五倍的惩罚性赔偿。范围不是本项目的估价、起诉后必得金额或所有案件的绝对上限。《民法典》第五百八十五条允许依法调整过低或过高的约定违约金；写一个固定数字也不等于法院必然支持。

保留实际创作记录、源文件、版本历史、权利来源和商业授权记录；发现疑似侵权时依法保存对方页面、发布包、收费情况及时间证据，交律师评估。Git 提交时间只是证据之一，不能代替权属证明。

以上为一般信息，不是针对具体案件的法律意见；实际适用的国家或地区不同，规则可能不同。
