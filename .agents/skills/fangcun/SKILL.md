# 方寸 FANGCUN｜互动演示制作 Skill

方寸是面向用户的项目名称；制作方法沉淀自 **YanDeck｜交互式网页演示制作系统**。不是只换标题的模板，也不是必须有海、船或旧单位品牌。

## 先看内容，再问；需求最多五项

读取用户消息、附件与已有项目，按 [需求入口](references/intake.md) 处理。**整个开工阶段最多五个问题，不是每轮五个。** 已知信息不重复问；没有回答的非关键项采用明示默认值。不要额外追加用途、页数、模型、导出、部署等问卷。

1. **内容与场景**：仅内容不足时请用户提供资料和使用场景；已有资料先阅读。现场讲低密度，自行阅读高密度；页数按内容决定。
2. **Logo**：方寸默认 Logo / 用户提供的 Logo / 无 Logo。
3. **风格**：海洋风 / 透明玻璃风格 / 双色风 / 根据内容给三种真实样页。风格与背景分开。
4. **动态背景**：明确给出 **默认动态海浪 / 上传自己的背景视频 / 不要动态背景** 三个选择；未选择默认不要。已选默认海浪时只确认是否保留或换自己的，不重新问一遍。
5. **首页文案与开场**：先根据内容提出“首页用『完整标题』、粒子字用『短词』，这样对吗？”；在同一项让用户选择 **保留粒子文字互动 / 简洁封面 / 直接进入内容**。复用旧 CSSC 效果，不复用 CSSC 文字或 Logo。[代码 C33、C37、C38]

无内容时先只问第 1 项；收到内容再一起处理余下缺失项。用户主动选样、改词是回复，不另起全面调查；agent 再主动发问（包括选样确认）必须计入五题预算。需要三样页时预留风格这一题，直接展示后询问一次选择，不先问一遍“要不要看样页”再多问一题。预算耗尽时汇总假设直接制作，只有缺少不可替代资料或事实无法成立时说明限制。

## 制作流程（按需读，不全量加载）

- **开工**：读 [intake.md](references/intake.md)，记录确认值、默认值及首页提炼依据。用户明确要保留原稿时优先读取其生成源，不能偷偷套新模板。
- **内容底稿与故事板**：读 [production-workflow.md](references/production-workflow.md)。区分原始事实、可见文案与交互设计；不捏造业务结论。
- **风格**：读 [style-catalog.md](references/style-catalog.md)，只读所选风格文档。海洋风有启动包；透明玻璃、双色风是已内化的设计规范，不冒称已有完整模板。无偏好先给三种真实首页样页，选定后扩展。
- **首页效果**：读 [homepage.md](references/homepage.md)。粒子词是内容关键词，不是自动替用户编造的品牌缩写。完整题名放标题区，确认短词后再生成。
- **舞台与工程**：读 [fixed-stage.md](references/fixed-stage.md)，完整包含 [viewport-base.css](references/viewport-base.css)。已内化 frontend-slides 固定舞台规则，无全局第三方 skill 依赖。
- **交互**：读 [interaction-patterns.md](references/interaction-patterns.md)。先抽象输入→状态→反馈→结论→重置，选择关系映射、流程、纠错、变量探索、模式切换或状态机。二维物理实验优先官方 Matter.js；离线时打包同一库，不自研替代。
- **实现**：所有可复用代码规则统一查 [code-reference.md](references/code-reference.md)。使用 `scripts/new_deck.py` 建独立 `decks/<topic-slug>/`，不覆盖既有稿件。有生成器时修改源再生成，不只改 HTML。
- **验收交付**：读 [qa-checklist.md](references/qa-checklist.md)，启动独立本地 HTTP 服务，实测与截图检查；通过后打开给用户验收。最后才问“要不要部署包？”；需要时包含启动脚本、依赖及 README。[代码 C15、C18、C36]
- **经验回收**：用户确认新风格后按 [style-extraction.md](references/style-extraction.md) 提炼，追加 registry 和代码编号，不覆盖旧风格。

## 必须守住的经验

- 1920×1080 固定舞台整体等比缩放，手机不重排；切页用可见性/透明度/指针状态，不用 display 切换。[代码 C01、C02]
- 普通页单击/空格/PageDown/滚轮先推进再翻页；控件、拖拽、实验区域不误翻页，滚轮有手势锁。[代码 C03、C09]
- 普通海洋页水面点击既回应波纹也推进；封面通过按钮进入；粒子序章点击散开并完整重组后进入。校验消息 origin、source 与当前页；隐藏场景暂停。[代码 C30、C31、C33]
- 玻璃模糊不参与入场动画；一页一个视觉重点，过满拆页。双色风保持暖白/近黑、克制黄、语义图形与共用几何连线，不变成常见双色模板。[代码 C14、C23—C30]
- 双色风与全屏动态海浪冲突时在第 3/4 项内说明并推荐纯色；用户坚持则仅放独立媒体窗口，不叠加成整页背景。
- 方寸 Logo 默认已授权用于本项目；CSSC 和旧业务专有文字不得默认继承。模型默认不用，船只和海浪仅明确选择后启用。[代码 C04、C05、C07]
- 粒子效果是可选开场，不是每个风格都强塞海洋粒子；双色风选粒子时改为符合其颜色纪律的版本或建议简洁封面，不能悄悄改成海洋风。
- 运行资源本地化、视频有 poster；减弱动效、键盘和 WebGL 失败后备可用。断外网但保留本地 HTTP 的独立验证才算离线测试。[代码 C06、C16、C18]
- 实验游戏未明确用途/形式时默认学生自己体验、单页游戏、无动态背景、方寸 Logo，无额外主体；默认不加粒子序章阻断操作。
- GitHub 只发布经过检查的仓库；客户内容、部署成品、用户媒体和私有素材不默认提交。当前用户只要求准备上传时，不创建远程仓库或推送。[代码 C39]
