# YanDeck 交付检查

## 1. 内容与品牌

- 页面顺序和可见文字与确认后的逐页文案一致。
- 新主题中没有 CSSC、船舶工程、重心、吊点或示例软件残留，除非用户明确要求。
- Logo 来自用户本次提供的资产，或使用项目已获授权的“方寸 / FANGCUN”默认资产；不存在 CSSC 品牌残留。[代码 C05]
- 页码、日期、作者、单位等信息正确。

## 2. 舞台与排版

- 在 `1920×1080` 截图中无文字溢出、卡片遮挡、媒体越界。[代码 C01、C02]
- 在 `1280×720` 和手机视口中仍显示完整的 16:9 舞台，只允许留黑边或留白，不允许重排。[代码 C01]
- 标题、正文和注释字号舒适；内容过多已拆页。[代码 C14]
- 动态背景上的文字对比度足够，poster 与视频画面都可读。[代码 C04]

## 3. 导航与逐项呈现

- 单击、空格、PageDown 和滚轮可以逐项推进再翻页。[代码 C03、C08]
- 方向键、PageUp、Home、End 行为正确。[代码 C03]
- 点击按钮、拖动对象、选择下拉框时不误翻页。[代码 C09]
- 返回上一页时状态可预测；进入交互页时不会残留上一轮定时器或动画。[代码 C09]

## 4. 交互

- 每个交互都有输入、状态反馈、结论和重置。[代码 C09—C13]
- 数值边界、拖动边界、快速连点、Escape 和切页中断均测试。
- 键盘可以到达控件，状态变化有文字反馈或 ARIA。[代码 C16]
- `prefers-reduced-motion` 下没有长时间或循环式强动效。[代码 C16]

## 5. 素材与离线

- 所有 `src`、`poster`、字体和 `fetch()` 路径均为本地相对路径。[代码 C04、C06]
- 视频加载失败时显示后备图，模型首帧存在。[代码 C04、C07]
- 断网后通过本地 HTTP 服务仍可完整播放。[代码 C15]
- 不直接依赖 `file://` 测试含视频、字体、Canvas 或 `fetch()` 的演示。[代码 C15]

## 6. 输出与回归

- 若有生成脚本，先运行脚本，再测试生成后的 `index.html`。[代码 C17]
- 检查浏览器控制台无错误；检查所有页 `.slide` 数量与故事板一致。[代码 C18]
- 至少截图检查封面、最密集内容页、最复杂交互页和结束页。[代码 C18]
- 离线包从全新解压目录启动一次；PDF 导出后逐页检查。[代码 C15、C18]
- 若支持 `?page=`，检查首页、末页和越界页码都能安全打开。[代码 C21]
- 若支持封面现场编辑，刷新后本地保存值仍正确且控件不会触发翻页。[代码 C03、C19]
- 打印或 PDF 中每页只出现一次，逐项内容完整，交互停在有意义的静态状态。[代码 C22]
- QA 通过后已启动本地 HTTP 服务，并在浏览器打开可验收版本；部署包只在客户确认需要后制作。
- 若制作部署包，包内有完整资源、启动脚本和 `README.md`，且已从全新解压目录验证说明可执行。[代码 C06、C15、C18]

## 7. 双色风专项

- 常规画面是否只使用暖白、近黑、克制黄和中性灰；软件身份色是否只停留在必要对象内部。[代码 C23]
- 暖白是否为默认包装画布，近黑是否只用于 B-roll、暗场连续或明确重音。[代码 C23、C27]
- 暖白与近黑页面是否保持同一网格、层级和动效逻辑。[代码 C23、C28]
- 是否误用了动态海浪、玻璃模糊、彩色渐变、霓虹、随机白点或无意义光斑。[代码 C04、C23]
- 标题、证据区、头像和字幕是否保持正确优先级，正文是否侵入字幕安全区。[代码 C25、C28]
- 黄色路径、移动点和箭头是否共享同一几何真源，并停靠在元素边界。[代码 C24]
- 是否存在穿字、穿卡片、穿字幕区，或为了避线删除信息的问题。[代码 C24、C25]
- 动画是否遵循节点先、路径后、结论最后，且没有高频弹跳和连续缩放。[代码 C24、C26]

## 8. 海洋风与可复用主题专项

- 普通页水面点击与沙滩点击一样推进步骤/翻页；控件不穿透。封面仅按钮进入，序章等粒子完整成型才切页。[代码 C31、C33]
- 章节船模没有悬停抬起，原命中/左右浏览/后备图正常。[代码 C32]
- 玻璃背景模糊恒定，不出现进页后忽然更磨砂。[代码 C30]
- 新主题来自独立风格包，换题名和粒子词后仍可生成；无原单位/专业文案残留、中文无缺字。[代码 C29、C35]
- 新目录独立服务且其他 origin 请求全部阻断时通过；默认关闭背景/模型也通过。文件 hash 不代替浏览器行为检查。[代码 C34、C36]
- 旧风格条目和文档原样保留，有版本/来源/变换/截图/测试记录。[代码 C34]

- 船模回归不能只检查 targetFrame > 0：必须冷启动、跨精灵图边界、到 149 帧再回 0、5/15/24 页切换，并确认 canvas 实际显示帧追上目标。先播放海洋/粒子再回章节，检查隐藏场景已停止绘制。[代码 C30、C32]
