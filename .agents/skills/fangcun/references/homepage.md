# 首页文案与粒子开场

## 从内容提炼，而不是照搬旧文字

首页负责让观众知道“谈什么、有什么价值”，粒子短词负责建立记忆点。先读资料，提炼主问题、变化或行动；专业报告保留准确题名，不能为了好看改掉业务意义。[代码 C38]

例：用户给的是动能实验资料，可以建议完整标题“让能量变化看得见”、粒子词“动能”，并说明这是表达建议；原题名要求不动时就不改。无事实支撑不要写“提升 300%”“行业第一”等。

默认只给一个最贴题候选，在第 5 项同时确认文字和开场形式。粒子支持 1–12 Unicode 字符，推荐 2–6 个中文或简短英文词；长标题不截断成乱码、不发明英文缩写，重新提炼短词，完整题名仍保留。[代码 C33]

## 三种形式

- `particles`：可替换文字的粒子序章 → 封面 → 正文。鼠标透视弯曲；点击错落散开；完整重组提交画面后发消息进入。不是自动成型就跳页。正常字形磁流、向外连续減密与慢微移保留，不变成同步呼吸/比例放大。[代码 C33、C37]
- `cover`：去掉粒子，直接从完整题名封面开始；进入按钮、键盘与滚轮都能继续。不要残留粒子 iframe/加载。
- `none`：去掉粒子与封面，直接内容或章节；适用于单页实验、嵌入展示、用户明确不需要开场的场景。至少保留一页。[代码 C38]

`homepage` 只过滤已有 `slides`，不会自动补造页面；新稿从默认数据启动时具有序章与封面，自有配置需要按选择包含相应页面。

## 品牌与风格解耦

粒子文字 ≠ Logo。换词不该改变左上品牌，换 Logo 不该将用户品牌名强制写进粒子。旧 CSSC 仅为效果历史来源，最终默认无其可见文字/单位信息。

海洋风已有可执行粒子模块。双色风默认建议简洁封面；用户坚持粒子时保留交互机制，但样页需校准暖白/近黑与克制黄，不能把青蓝渐变/玻璃素材偷渡进去。透明玻璃风按选定系统调整。[代码 C23、C33]

## 必测

换成真正中文关键词后测字库；分别测三种形式。序章初次成型不翻页，点击重组只切一次，切走后暂停；同 origin/source/当前页才接受完成消息。键盘可触发或跳过，触屏可点击，减弱动效和 WebGL 失败时不能困住观众。封面/正文不误继承 iframe 焦点与点击处理。[代码 C16、C31、C33]
