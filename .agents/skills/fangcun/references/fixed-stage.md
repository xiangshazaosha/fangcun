# 固定舞台与工程基础

从 frontend-slides 的项目内版本内化；其基础 CSS 及 MIT 声明随项目保存，不依赖原机器的全局 skill。

- 创作坐标固定 1920×1080；使用完整 `viewport-base.css`，整体均匀缩放到窗口，允许留边，不做手机内容重排。[代码 C01]
- 页面绝对定位；`.active/.visible` 控制 visibility、opacity、pointer-events，非活动页不拦截事件。不能用 display:none/block 切页。[代码 C02]
- 普通内容逐项推进；操作区事件隔离；滚轮累计阈值、一次手势锁、支持键盘首尾和前后。[代码 C03、C08、C09]
- 低密度一页一重点，高密度可读但不堆到溢出。字体先核对字形，用完整本地字体；不要让换内容后只剩缺字方框。可以按稿件生成子集，但保留授权文件。[代码 C06、C14]
- 零构建依赖优先：HTML/CSS/JS 本地运行；需要 Three.js/Matter.js 时保存官方库及许可证。Node 仅用于开发 QA，浏览器播放不要求 npm。[代码 C06]
- 有生成器时它与模块/数据是源；单文件、小稿可直接维护 HTML。都不能将用户磁盘绝对路径写入运行资源。[代码 C17]
- 真实浏览器截图同时检查舞台比例、文字裁切、卡片遮挡；DOM scrollHeight 不能证明视觉无覆盖。减弱动效、失败后备、打印最终态都须实测。[代码 C16、C18、C22]
- 浏览器首选专用工具或本地 Playwright 自动测试；不默认 computer-use。若唯一可行路径是 computer-use，先说明原因并取得明确同意。
