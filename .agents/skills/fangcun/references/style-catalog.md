# YanDeck 风格分类

风格与背景是两回事：风格控制排版、材质、色彩关系和动效；背景单独选择动态海浪、自定义视频或无动态背景。[代码 C04、C14]

## 1. 透明玻璃风格

**状态：可用。**

这是较早版本提炼出的通用透明玻璃材质风格；本次完整海洋场景另列为海洋风。特征包括：环境画面可见、透明磨砂内容层、低透明高光、克制渐变、强中文标题、章节舞台、逐项高亮与局部交互反馈。[代码 C04、C08、C14、C20]

需要使用时读取 [styles/transparent-glass.md](styles/transparent-glass.md)。

它可以搭配三种背景：

1. 默认动态海浪。[代码 C04]
2. 用户上传的动态背景。[代码 C04]
3. 无动态背景，改用纯色、渐变或静态图。[代码 C14]

## 2. 双色风

**状态：可用。**

双色风已根据用户的 Remotion 风格归档和六张长视频实拍画面完成演页化抽取。它不是泛指“任意两种颜色”，而是以暖白空间和克制黄为识别锚点，以近黑和中性灰建立层级；近黑整页只服务于 B-roll、暗场连续性或明确的重音段落。[代码 C23]

需要使用时读取 [styles/two-tone.md](styles/two-tone.md)。

双色风默认选择“不要动态背景”。动态海浪不属于该风格；如果用户同时选择两者，应先处理冲突。[代码 C04、C23]

## 3. 海洋风

**状态：可用，含独立可运行启动包。**

本篇最终成品的完整视觉与交互体系：浅海/沙滩空间、青蓝与潟湖绿、稳定磨砂玻璃、粒子序章、章节主体舞台。当前配套实时海洋里是三条锦鲤，不是旧海浪 MP4。[代码 C29–C33]

读取 [styles/ocean.md](styles/ocean.md)。背景和船模单独显式选择，不选则不加载；新选题默认方寸 Logo。用 new_deck.py 从注册表创建，不搬原成品业务内容。[代码 C35]

## 4. 自定义风格

用户不选择现有风格时，根据内容与品牌制作三张真实标题页预览，用户选定后把所选方向整理为该演示自己的主题变量与版式规则。[代码 C14]

预览页不得出现“方案 A”“模板名”“预览”等内部流程文字；页面必须像真实成品首页。

## 分类与扩展规则

机器索引：[styles/registry.json](styles/registry.json)。新增方法：[style-extraction.md](style-extraction.md)。每种风格一个 id/独立目录与证据记录；双色风仍保持 C23–C28 的原设计与实现规则，海洋风使用 C29–C36，不混用背景、资产或默认文案。
