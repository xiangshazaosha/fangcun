# YanDeck 通用交互模式

当前成品中的三视图、重心和吊点等内容不可直接复用，但它们背后的交互逻辑可以复用。所有交互都先写清：`输入 → 状态 → 反馈 → 结论 → 重置`。[代码 C09]

## 1. 关系映射

**适合：** 多个问题分别对应流程节点、能力模块或解决方案。

- 输入：经过、聚焦或单击某个问题。
- 状态：当前问题被预览或锁定。
- 反馈：相关节点与连线高亮，旁边解释变化。
- 结论：观众看出“这个问题由哪些环节解决”。
- 重置：再次单击、点击空白或按 Escape。

来源思路：当前成品的问题诊断地图。复用映射与锁定机制，不复用具体工程节点。[代码 C10]

## 2. 流程推进器

**适合：** 数据、订单、项目、审批、制造或学习流程。

- 输入：拖动一个代表对象的 token，或点击阶段节点。
- 状态：进度值映射到离散阶段。
- 反馈：当前阶段、产物和检查状态同步更新。
- 结论：观众理解每一步改变了什么。
- 重置：拖回起点或提供重置按钮。

来源思路：当前成品的数据闭环拖动。复用进度映射，不复用文件名和工程产物。[代码 C11]

## 3. 检查与纠错实验

**适合：** 表格规范、配置检查、质量验收、风险排查。

- 输入：点击“开始检查”，再切换一个错误条件。
- 状态：等待、扫描、失败、已修复、通过。
- 反馈：定位问题位置，显示错误原因和修复动作。
- 结论：用户学会如何判断输入是否合格。
- 重置：恢复初始数据或重新检查。

来源思路：当前成品的表头检查和缺失标记模拟。复用验证状态机，不复用字段名称。[代码 C13]

## 4. 变量探索器

**适合：** 价格、资源、风险、时间、比例、物理量或任何参数关系。

- 输入：拖动对象、滑块或数字控件。
- 状态：保存参数值并实时计算派生结果。
- 反馈：位置、长度、数值、公式或图表同步变化。
- 结论：用户亲自看见“变量怎样影响结果”。
- 重置：恢复基准值；可选自动演示。

来源思路：当前成品的重心与分力实验。复用参数映射和实时反馈，不复用公式与坐标定义。[代码 C12]

## 5. 模式切换与空间反馈

**适合：** 多视角、多方案、多版本、多图层或不同运行模式。

- 输入：选择模式或对象。
- 状态：当前模式和步骤。
- 反馈：主画布、标注、日志和结论同步切换。
- 结论：观众理解不同选择如何改变结果。
- 重置：回到默认模式。

来源思路：当前成品的视图选择与落图过程。只复用“模式 → 画布反馈 → 日志”的结构。[代码 C13]

## 6. 阶段状态机

**适合：** 操作培训、审批流、故障恢复、撤销/退出逻辑。

- 输入：按钮、键盘或步骤动作。
- 状态：有限数量的明确阶段。
- 反馈：当前节点、已通过节点、事件日志和下一步提示。
- 结论：用户理解同一动作在不同阶段的结果。
- 重置：返回起点。

来源思路：当前成品的 ESC 回退/退出实验。复用状态机和事件日志，不复用原软件规则。[代码 C13]

## 7. 动态主体浏览

**适合：** 产品外观、设备结构、建筑、角色或载具。

- 输入：鼠标左右移动、拖动或滚轮。
- 状态：当前视频时间或帧号。
- 反馈：主体按输入旋转或变化。
- 结论：用户主动查看主体，而不是被动看循环视频。
- 重置：离开有效区域后回到静止帧或保留当前位置。

透明主体可用 WebM、连续 WebP 或精灵图；普通视频则可直接循环。始终准备静态后备图。[代码 C07]

## 8. Matter.js 物理实验

**触发：** 用户说“做实验”“物理实验”或“实验游戏”，并且实验可由二维刚体、重力、碰撞、摩擦、斜面、摆、弹簧或约束关系表达。

- 先从教学目标反选实验，不先画一个无关的物理沙盒。题目不明确时，选择适合受众阶段、变量清楚且有可测结论的经典实验。
- 使用官方 Matter.js 库；物理引擎负责运动、碰撞和约束，DOM/SVG/Canvas 负责量尺、数值、任务与解释层。普通联网网页可通过 CDN 或包管理器引入；离线、内网或单文件交付时，将同一个 Matter.js 库打包或内联，避免运行时网络依赖。
- 实验必须保留控制变量意识：一次突出 1–2 个自变量，其余条件固定并明示。
- 交互闭环仍为 `输入 → 物理状态 → 测量反馈 → 知识结论 → 重置`；游戏化目标不能取代知识结论。
- 提供“开始/释放”和“重置”，运行中锁定会破坏实验条件的控件；切页或重新开始时停止旧 Runner、事件监听和定时器。[代码 C09]
- 读数说明单位、近似关系或相对量，不能把像素和 Matter.js 内部单位冒充真实实验精度。
- 交付前至少验证一个低值、一个高值和一个边界组合，检查快速连点、重复重置与减弱动效。[代码 C16、C18]

若主题本质上不是二维物理过程，不为了满足“实验”字样硬套 Matter.js；改用最贴合的变量探索器、状态机或检查实验，并说明选择。

## 9. 选择原则

- 一页最多一个主要交互。
- 交互控件必须阻止冒泡，避免点击控件时翻页。[代码 C09]
- 同一章节通常只需一两个关键实验；其余页面用逐项呈现即可。[代码 C08]
- 如果交互没有可说出的结论，就改为静态图。
- 每个实验要有初始提示、当前状态、结果文字和重置入口。[代码 C09]
- 不把鼠标悬停作为唯一操作方式；同时支持聚焦、单击或键盘。[代码 C10、C16]
