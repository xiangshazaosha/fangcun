# 五项需求入口

**使用对象：未来委托方寸制作自己演示稿的用户。** 维护、打包或发布本 skill 时不向作者发这份问卷，也不展示测试 PPT。下面是制作 agent 的需求判断方法，非固定表单。

## 控制提问预算

先解析内容和已知选择，用五个槽位保存需求：`content / logo / style / background / homepage`。不是把十多个问题塞进五个编号：每项只解决一个决策域，页数、动态主体、作者日期等没有要求就推断或不添加。已知项不提问；修改原稿只问本次变化项。

记录在本次 `decks/<topic>/requirements.json`，包含 `askedCount`、`provided`、`inferred`、`defaults` 和 `homepageProposal`。`askedCount` 是实际提出的问题数；开工全程 ≤5，包括必要的补充确认。用户主动补充不算新问题。预算用完用明确默认值继续，不反复“还有最后几个问题”。

先阅读材料再提炼首页。若材料未提供，只问内容，不先拿 FANGCUN 当主题文案发出空泛问卷。提供的文件读不了时说明限制，不声称已阅读。

## 可直接采用的自然问法

**背景与粒子开场是必须主动询问的两项。** 用户已明确给答案时无需重复问；否则须预留这两个槽位，不允许用默认值跳过。即使用户先要几张试稿也先问，未答只能将临时关闭记作 pending。只有文稿规划或维护 skill 时可先不启动制作问卷。

只列缺失项，不必每次完整照抄。

1. **内容**：“请发这次的文案或资料，并说一句使用场景（现场讲，还是给别人自己看）；页数没要求我按内容安排。”
2. **Logo**：“Logo 用方寸默认标志、换你提供的，还是不放？”
3. **风格**：“想用海洋风、透明玻璃风格、双色风，还是我根据内容给三种真实样页？”
4. **背景**：“背景选默认动态海浪（也可用内置锦鲤海洋）、上传自己的背景视频，还是不要动态背景？”已有稿件则改为“现在的背景保留，换成你自己的，还是去掉？”未回答只能暂不加载，不视为用户选择不要。
5. **首页**：“根据资料，首页建议用『让能量变化看得见』，粒子字用『能量』，这样对吗？开场选保留粒子文字互动、简洁封面、直接进入内容。”

第 5 项中的示例必须替换为**本次资料得出的实际建议**。可以回复“保留效果，字改成××”或“标题不动，取消粒子”，不强迫用户使用格式。

## 用户已给内容时的实际工作方式

先给一句内容理解与制作建议，例如“这份资料重点是把流程讲清楚，我建议做成现场讲解型演示，页数按章节拆分。”然后只问尚未确定的 Logo、风格、背景、首页四项。首页项必须展示根据资料拟定的真实标题/短词，不能问“你想首页写什么”后把提炼工作甩回用户。

用户说“就用现有方寸那套，只换内容”时，继承已确认的 Logo、风格和效果；只提出新首页文字的确认，以及原背景是否要换自己的素材，不再重问整套选择。若用户已经说背景也不变，则连这一题都省略。页数与密度由资料/场景判断，先给建议，而不是追加一张调查表。

材料已提供的首轮应直接给一句理解和首页候选，再列余下缺失项；不要重新问“有没有文案”。需要三样页时预留第 3 项，制作样页后只问一次选哪个；如果已经问过风格，又主动问样页选择，则也计一题，不能借“同一个领域”绕过总量。预算用完可展示推荐方案但不追加选择问句，用户可主动修改。需求未答默认值需在开工摘要明示；不是暗中替用户批准新品牌文字。

## 默认与继承

| 领域 | 新稿无选择 | 已有稿只改内容 |
|---|---|---|
| 使用与篇幅 | 场景可推断则采用；否则现场讲低密度，页数按内容 | 保留原要求，过满自动拆页并说明 |
| Logo | 方寸/FANGCUN | 保留本次合法品牌；跨主题不继承旧 CSSC |
| 风格 | 根据内容出三样页，未选可用推荐方向试做 | 保留原风格 |
| 背景 | 必须先问；未答暂用 none 并记 pending | 保留已选择的背景；未明确是否继承则问保留/替换/去掉 |
| 首页 | 必须问粒子开场；给完整标题+短词，未答仅做待确认临时样页 | 明确继承互动效果时保留，提出本次换词建议，不保留旧单位词 |
| 模型 | none；用户明确提供并要求才用 | 保留与新内容相关、明确要求的模型 |
| 实验 | 学生体验、单页、无粒子序章 | 按用户指定形式 |

视频选择时上传视频本身即是第 4 项回复，poster 可从视频抽帧，不再提一个额外问题。只有具体文件损坏或无授权不能继续时才说明限制。实时海洋鱼群不等于默认海浪视频；用户明确选择实时海洋时用 `ocean`，不为了“海洋风”偷偷替选。[代码 C04、C30、C35]

## 转为实现值

- Logo：默认 `brand/fangcun-logo.svg`，自有资源用相对路径，无 Logo 是空字符串。
- 背景：不要→`none`；默认海浪→CLI `waves`（输出映射为 `video`）；上传→`video` + `video/poster`；用户明确要实时海洋→`ocean`。
- 内置锦鲤海洋就是 `ocean`，资源目录和独立导出见 [backgrounds.md](backgrounds.md)。这是游鱼/波纹，不是钓竿捕鱼游戏；“钓鱼”称呼有歧义时先核对资产，不凭名称编造新场景。
- 首页：保留粒子→`homepage=particles` + `particleText`；简洁封面→`homepage=cover`；直接内容→`homepage=none`。
- 将完整题名写入 `title` 和 cover 的 `title`，粒子短词写入 `particleText`。不把整份文案写进粒子参数。
- 样页/建议未经选择时使用 `inferred` 或 `pending` 标记；用户明确确认才记 `provided/confirmed`。
